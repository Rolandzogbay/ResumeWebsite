# Roland CV

## Project Overview
**Roland CV** is a static personal website built using **HTML** and **CSS**.  
It is designed to showcase my professional background, education, skills, projects, and contact information in a clean and visually appealing format.  
This project is part of my **FullStack Web Development journey at Orange Digital Center (ODC)** and serves as my first hands-on web development project.  

---

## Features
- **Header Section:** Displays name, professional title, and contact information.  
- **Profile/Summary:** A brief description highlighting personal and professional background.  
- **Education Section:** Lists academic achievements and qualifications.  
- **Experience Section:** Details previous work, volunteer roles, or internships.  
- **Projects Section:** Showcases small projects and practical exercises.  
- **Skills Section:** Lists technical and soft skills.  
- **Certifications & Training Section:** Highlights ongoing or completed training.  
- **Optional Interests/Hobbies Section:** Adds personality to the resume.  
- **Footer:** Contains social media links and a signature line.  

---

## Technologies Used
- **HTML5** – Structure and semantic markup.  
- **CSS3** – Styling, layout, and responsive design.
